#Switching between training and testing
Super simple now:

Training
Select Board GameObject in Hierarchy

In Inspector → tick trainingMode ✅

Run mlagents-learn command in terminal

Press Play

Testing
Select Board GameObject in Hierarchy

In Inspector → untick trainingMode ☐

Select your Agent GameObject → Behavior Parameters → drag .onnx into Model field → set Behavior Type to Inference Only

Press Play — clean board, agent runs the model

That's the full switch. One checkbox + one model swap.
